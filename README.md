## ✨ 주요 기능

1. **💡 로직 구상실 (Blueprint Studio)**
   - 목표 정의 → 입력 데이터 → 조건/반복 로직 → 최종 출력의 4단계 IPO 패턴 구상
   - 정리한 아이디어를 원클릭으로 파이썬 뼈대(스켈레톤) 코드로 자동 생성

2. **💻 모바일 특화 스마트 에디터 & 퀵 툴바**
   - 작은 화면에서도 편안한 가상 키보드 퀵 툴바 (`Tab`, `Shift-Tab`, `:`, `()`, `""`, `print`, `if`, `for`)
   - `.py` 소스코드 파일 다운로드(내보내기) 지원

3. **💬 실시간 대화형 인터프리터 (REPL)**
   - `>>> ` 프롬프트에서 한 줄씩 실시간 평가 및 즉시 결과 출력
   - 직전 명령어 히스토리 탐색 (`▲`, `▼`)

4. **📟 브라우저 온디바이스 파이썬 실행 (Pyodide WASM)**
   - 서버 비용 0원, 웹 브라우저 내에서 안전하게 파이썬 3.11 코드 실행
   - `input()` 실행 시 스마트폰 전용 모달 팝업 지원
   - 초보자 친화적 한국어 에러 통역기

5. **📚 입문자 퀘스트 (Starter Quests)**
   - 자기소개기, 미니 계산기, 홀짝 판별기, 업다운 게임, 구구단 출력기

## 📲 스마트폰 앱(PWA) 설치 방법

1. 스마트폰 브라우저(Chrome, Safari, 삼성인터넷)에서 배포된 웹사이트 주소 접속
2. 브라우저 메뉴(또는 주소창 우측)에서 **"홈 화면에 추가"** 또는 **"앱 설치"** 터치
3. 스마트폰 바탕화면에 생성된 **PyPocket** 아이콘을 눌러 전체 화면 앱으로 실행!
